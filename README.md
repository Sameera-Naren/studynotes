# 🎓 Study-Notes

A Discord-inspired collaborative learning platform that enables students to create study groups, share knowledge, and learn together in real-time.

![LearnTogether](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## 📋 Overview

This is a modern web application designed to facilitate collaborative learning through study groups. With a sleek, Discord-inspired interface, students can create or join study groups, participate in real-time discussions, and build a supportive learning community.

## ✨ Features

- 🔐 **User Authentication** - Secure registration and login system
- 👥 **Study Groups** - Create and manage collaborative study groups
- 💬 **Real-time Messaging** - Chat with group members in dedicated channels
- 🔗 **Invite System** - Share unique invite links to grow your study groups
- 📱 **Responsive Design** - Fully functional on desktop and mobile devices
- 🎨 **Modern UI** - Clean, Discord-inspired interface with smooth animations
- 👤 **Member Management** - Track group members and their activity

## 🛠️ Tech Stack

### Frontend
- **HTML5** - Semantic markup
- **CSS3** - Modern styling with animations and transitions
- **JavaScript (ES6+)** - Dynamic functionality
- **Lucide Icons** - Beautiful icon library
- **date-fns** - Date formatting and manipulation

### Backend (MongoDB Integration)
- **Node.js** - Runtime environment
- **Express.js** - Web application framework
- **MongoDB** - NoSQL database
- **Mongoose** - MongoDB object modeling
- **JWT** - Authentication tokens
- **bcrypt** - Password hashing

### Tools & Libraries
- **Vite** - Build tool and development server
- **nanoid** - Unique ID generation
- **Axios** - HTTP client for API requests
